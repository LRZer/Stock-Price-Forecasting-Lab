# 次日涨跌预测：准确率与上涨概率

## 先看懂这个任务

在第 t 个交易日收盘后，用当天及以前的信息预测**下一交易日收盘价是否上涨**。若下一收盘价高于今天，真实标签为“上涨”；持平记入“未上涨”。分类模型输出 0–1 之间的上涨概率；概率达到 50% 就判断上涨，否则判断未上涨。例如预测上涨概率 60%、次日确实上涨，这一天就算判断正确。

**涨跌准确率 = 判断正确的交易日数 ÷ 测试交易日数。** 但准确率不能只与 50% 比：如果某段时期本来有 55% 的日子上涨，天天猜上涨就能达到 55%。项目因此加入“训练期多数方向”基线：只用训练期数据决定较常见的方向，再在测试期每天猜该方向。另报告 Brier 误差（预测概率与真实 0/1 标签之差的平方平均，越低越好），用于检查“60%”这类概率本身是否可信。准确率高不保证概率可信。

## 20 类神经网络直接做涨跌分类

原有 18 类网络及新增的残差时间卷积、注意力 GRU，均以“次日上涨 / 未上涨”作为训练标签并输出上涨概率；输入为预测日前 20 个交易日的 OHLCV 历史特征。另有使用相同历史输入的简单模型作对照。下表只在预先固定的六个主要候选中按验证期选模；20 种网络和传统模型的逐项结果见 [NEURAL_CLASSIFIERS.md](../results/NEURAL_CLASSIFIERS.md)。

| 股票 | 2025 固定测试期（148 天） | 固定期多数方向基线 | 三轮滚动测试（300 天） | 滚动期基线 |
| --- | ---: | ---: | ---: | ---: |
| GOOG | 92/148 = 62.2% | 85/148 = 57.4% | 161/300 = 53.7% | 162/300 = 54.0% |
| AAPL | 67/148 = 45.3% | 82/148 = 55.4% | 159/300 = 53.0% | 161/300 = 53.7% |
| TSLA | 76/148 = 51.4% | 79/148 = 53.4% | 145/300 = 48.3% | 151/300 = 50.3% |

GOOG 固定期多对 7 天，但三轮滚动少对 1 天；AAPL、TSLA 两种评测都落后。冻结规则后在新股票 ACN、RMD 上又分别比基线少对 3 天、多对 1 天。新增结构没有表现出稳定优势。混淆矩阵、概率分箱、随机种子对照和外部检查解读见 [IMPROVEMENT_REPORT.md](../results/IMPROVEMENT_REPORT.md)。

## 为涨跌任务专门训练的轻量分类模型

候选模型为多数方向基线、逻辑回归和小型梯度提升树；后两者分别使用收盘价特征与 OHLCV 特征。每轮按验证准确率选模型，若准确率相同，再用验证 Brier 误差决定。预测时点、特征和时间划分见 `stocklab/direction_study.py`。

2022–2025 年三轮滚动测试，每只股票合计 300 个测试交易日：

| 股票 | 每轮按验证集选模后的正确天数 / 准确率 | 多数方向基线 |
| --- | ---: | ---: |
| GOOG | 157/300 = 52.3% | 162/300 = 54.0% |
| AAPL | 159/300 = 53.0% | 161/300 = 53.7% |
| TSLA | 163/300 = 54.3% | 151/300 = 50.3% |

TSLA 三个测试窗口中，选中模型分别为 63%、46%、54%，表现仍有波动。逐轮结果在 `runs/direction-study/rolling/`。

2026-01-02 至 2026-09-25 的 184 个交易日另作**回顾性检查**：

| 股票 | 验证集选中模型 | 正确天数 / 准确率 | 多数方向基线 | 所选模型 Brier / 基线 Brier |
| --- | --- | ---: | ---: | ---: |
| GOOG | 多数方向 | 87/184 = 47.3% | 47.3% | 0.253 / 0.253 |
| AAPL | 逻辑回归 + OHLCV | 95/184 = 51.6% | 53.3% | 0.251 / 0.249 |
| TSLA | 逻辑回归 + OHLCV | 100/184 = 54.3% | 50.5% | 0.252 / 0.250 |

TSLA 比基线多判断正确 7 天，但它的概率 Brier 误差略高于基线。2026 年的价格走势已在先前实验中查看，因此这里**不是新的、未触碰的样本外证明**。完整的每个候选模型结果、每日上涨概率和按时间切分信息仅在本地 `runs/direction-study/retrospective-2026/` 归档；公开仓库不包含这段逐日结果。

两段时期的模型与基线并排图见 [准确率对照图](../../runs/direction-study/accuracy_comparison.png)。

## 旧版价格网络换算出的方向准确率

旧版的 18 类网络输出**收盘价**，训练目标也是价格误差。可将“预测价高于今天实际收盘价”换算成上涨判断；这些价格网络**没有直接输出上涨概率**。按验证期方向准确率从旧版网络与多数方向基线中选择时，2025 年测试期的结果为：GOOG 63/148 = 42.6%（基线 57.4%），AAPL 82/148 = 55.4%（基线 55.4%），TSLA 69/148 = 46.6%（基线 53.4%）。旧版逐项数据见 [NEURAL_DIRECTION.md](NEURAL_DIRECTION.md)，勿与上面的直接分类训练混淆。

这些回顾性结果说明，改用容易理解的指标有助于看清模型是否真的抓住涨跌；单次略高于 50% 或单期胜过基线，不足以证明它能稳定预测未来。
