# 新股票外部检查：运行前固定的规则

本文件在查看新股票测试结果前写定。最初预定 JPM、XOM，但原数据源没有 JPM 文件（下载返回 404）；查阅数据源公开目录后，在下载可用数据前改为 ACN、RMD。此替换仅因文件可用性，不依据模型成绩。这个检查用于观察模型能否迁移到原有三只科技股之外；它仍是同一历史市场时期的回顾性检查，不等同于未来实时预测。

- 股票：ACN、RMD。来源和日期与现有小型数据集相同，2022-01-01 至 2025-12-31；每只约 1000 行。只新增这两只，控制训练量。
- 标签：次日收盘价严格高于当日收盘价为“上涨”；持平为“未上涨”。20 个已知交易日的 OHLCV 相对特征作为输入，目标日不进入输入。
- 切分：每只股票的可预测目标按时间顺序 70% 训练、15% 验证、15% 测试。归一化只用训练期。
- 固定六个主要候选：训练期多数方向、`logit-window`、`gbdt-window`、`gru`、`tcn-residual`、`gru-attention`。网络隐藏宽度 32，随机种子 42，最多训练 20 轮，验证 Brier 选训练轮次，连续 5 轮未改善即停止。逻辑回归与梯度提升树的参数由代码固定。
- 用验证集**准确率最高、同分时 Brier 最低**的候选作为该股票的选择；测试集只报告。判涨阈值 0.5。
- 事先关心的指标：正确天数/总天数、多数方向基线、平衡准确率、Brier 误差、混淆矩阵和概率分箱。不以本次测试结果调整候选、窗口、特征或阈值。

原有 GOOG、AAPL、TSLA 的 2025 与 2026 年结果已经查看；本检查只提供**新股票的外部对照**。即使一两只股票高于基线，也不能单独证明稳定预测能力。真正按未来时间推进的检验仍需等待新的交易日数据。
